我們找到的案例

用名稱和範例，建立共同語言的人們

這些貼文的作者，把請 AI 做事時可以用的名稱，連同會動的範例或速查表一起整理公開。領域、語言和外觀各不相同。我們只挑選附有作者自製範例的貼文；貼文的內容與權利屬於各作者。

列在這裡，不代表作者支持本網站。介紹文字由本網站撰寫。

關於嵌入內容

本頁以 X（前身為 Twitter）的嵌入方式顯示每則貼文。開啟後會從 X 的伺服器載入，並使用 X 的 Cookie。X 可能會記錄這次瀏覽並用於廣告。載入時，我們會加上要求 X 不要用於個人化的設定（dnt）。

推薦貼文（也歡迎自薦）

如果看到有人把名稱附上範例公開的貼文，請透過 GitHub 的 Issue 告訴我們，自己的貼文也可以。我們只放嵌入內容和連結，不會把圖片或影片複製到本網站。

推薦案例（GitHub Issue）

希望移除時

如果想移除自己的貼文，或介紹文字有誤，請透過 Issue 表單提出。確認後，我們會盡快移除。
