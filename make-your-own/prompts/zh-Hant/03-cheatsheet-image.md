# 提示詞 3：做出一頁式的速查表圖片

把這份提示詞貼給能準確畫出文字的圖像生成 AI 使用。如果你的工具可以附上參考圖片，請附上 `make-your-own/examples/camera-moves/en/cheatsheet.png` 作為版面參考。

請替換 `<...>` 的部分和 24 行文字。這裡保留了運鏡的文字，作為填好的範例。

下面寫的版面、顏色和圖示風格，是運鏡範例的外觀，不是規定。請把這幾行改成符合你自己影片的樣子。另一個外觀不同的填寫範例（深藍底配彩色縮圖，日文）在 [`examples/motion-graphics/ja/cheatsheet-prompt.md`](../../examples/motion-graphics/ja/cheatsheet-prompt.md)。

圖像生成模型有時還是會把字寫錯。請多做幾個版本，選定一張之後，在發布前把每一行都和你的清單對照一遍。

```
請製作一張繁體中文的速查表圖片。<如果有附上參考圖片：保留它的版面、氛圍、配色和圖示風格，
但不要照抄它的任何文字。只使用下面的文字。>

## 輸出
- 長寬比 8:9（例如 1024x1152）。一開始就以 8:9 構圖，之後不需要再裁切或補邊。
- 做 3 個版本。版本之間稍微改變間距、字級和圖示的畫法。

## 版面
- 最上方：粗體的黑色大標題「<24 個運鏡與轉場 速查表>」；下方是灰色的副標題
  「<編號與影片相同，把名稱直接寫進提示詞>」
- 白色到極淺灰色的背景。每個區塊一個圓角框（淺灰色細框線）。區塊標題用藍色。
- 每一行：左邊是藍色線條圖示（小圓角方塊裡畫著該項目的簡單圖）→ 藍色編號 →
  黑色粗體名稱 → 灰色的一句話說明。各欄像表格一樣對齊。
- 最下方：淺灰色色帶裡的一行字。
- 顏色：只用一種藍色強調色 + 黑色 + 灰色。不用表情符號、照片或漸層。
- 24 行必須放進 8:9 裡。間距可以稍微緊一點，但文字必須保持清晰、容易閱讀。

## 文字（完全照寫，一字不差。不要改寫、縮短或增加。
## 「｜」是欄位分隔符號，不要畫出來）
區塊標題 1：影片 1/3　鏡頭運動　01–08
01｜橫搖（Pan）｜攝影機原地左右轉動
02｜直搖（Tilt）｜攝影機原地上下轉動
03｜Dolly in｜攝影機本身朝被攝體前進
04｜Zoom in｜只用鏡頭放大（攝影機不動）
05｜跟拍（Tracking shot）｜跟著被攝體一起移動
06｜環繞運鏡（Orbit）｜繞著被攝體轉一圈
07｜升鏡（Crane up）｜攝影機往上升起
08｜希區考克變焦（Dolly zoom）｜主體不變，背景被拉扯變形
區塊標題 2：影片 2/3　拍攝手法與時間效果　09–16
09｜焦點轉移（Rack focus）｜焦點從前景移到後景
10｜手持（Handheld）｜刻意加上輕微的晃動
11｜FPV 穿越機｜高速、身歷其境的穿梭飛行
12｜荷蘭角（Dutch angle）｜讓畫面斜向傾斜
13｜慢動作（Slow motion）｜把動作放慢播放
14｜速度漸變（Speed ramp）｜同一個鏡頭中途改變速度
15｜縮時攝影（Time-lapse）｜把幾個小時壓縮成幾秒
16｜定格（Freeze frame）｜讓動作停住一拍
區塊標題 3：影片 3/3　轉場　17–24
17｜跳接（Jump cut）｜同樣的構圖，時間往前跳
18｜匹配剪接（Match cut）｜用相同的形狀或動作接到下一個鏡頭
19｜甩鏡（Whip pan）｜快速橫搖，在模糊中接到下一個鏡頭
20｜交叉溶解（Cross dissolve）｜一個鏡頭漸漸疊化成下一個
21｜擦除轉場（Wipe）｜一條移動的邊界把畫面換掉
22｜Smash cut｜突然切到反差很大的場景
23｜J-cut｜下一場的聲音先進來
24｜L-cut｜上一場的聲音延續過來
最下方的一行：名稱再加上時間、速度和方向，結果會更準：「花 3 秒」／「慢慢地」／「朝被攝體前進」

## 圖示（藍色線條畫，小而簡單）
橫搖 = 水平雙向箭頭 + 攝影機，直搖 = 垂直雙向箭頭，Dolly in = 軌道上的攝影機加上向前的箭頭，
Zoom in = 鏡頭加上放大的箭頭，跟拍 = 人和攝影機並排加上箭頭，環繞運鏡 = 繞著人的弧形箭頭，
升鏡 = 搖臂加上向上的箭頭，希區考克變焦 = 同一個人加上向外擴張的畫框四角，焦點轉移 = 前景模糊／
後景清晰，手持 = 波浪線，FPV 穿越機 = 無人機，荷蘭角 = 傾斜的長方形，慢動作 = 蝸牛，
速度漸變 = 由快到慢的曲線，縮時攝影 = 時鐘，定格 = 暫停符號，跳接 = 兩個一模一樣的畫框，
匹配剪接 = 圓形 -> 圓形，甩鏡 = 動態拖影線，交叉溶解 = 兩個重疊的畫框，擦除轉場 = 一條橫越畫面的
分隔線，Smash cut = 閃電，J-cut = 音訊條在影像條「之前」（聲音先進來），L-cut = 影像條之後
接著音訊條（聲音延續到後面）。
```

## 小技巧

- 每一行都給一個圖示提示。沒有提示的話，模型容易替不同的行畫出相似的圖示。
- 如果要把圖片和影片放在一起發布，之後再把圖片縮放成和影片相同的尺寸（1200x1350）。
- 想讓中文名稱和英文名稱各占一欄的話，就多加一欄：`編號｜中文名稱｜英文名稱｜說明`，並在「版面」段落裡一併說明。
