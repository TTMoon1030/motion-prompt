請使用「滑鼠跟隨效果」（Cursor follower），這是「Landing Page 與網站效果」裡的一個名稱。
Motion Prompt #083

它是什麼：一個圓形延遲跟隨滑鼠游標移動
範例中會發生的事：游標在頁面上移動時，一個橘紅色圓形稍微落後地跟在後面。
規格：
- 游標路徑：x = 255 + 175·sin(2πt/4.8)，y = 86 + 46·sin(4πt/4.8)（橫躺的 8 字形，每 4.8 秒繞一圈）。
- 圓形：半徑 17，橘紅色，不透明度 0.88，畫在游標下層。
- 跟隨規則：每一影格（60 fps）移動剩餘距離的 12%（x += (游標 x − x) × 0.12）。
- 箭頭游標保持顯示。
使用時機：想在品牌網站或作品集網站增加互動感與趣味時。
