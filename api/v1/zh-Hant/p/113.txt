請使用「High Key（高調）」（High-key），這是「攝影風格：光線、鏡頭與調色」裡的一個名稱。
Motion Prompt #113

它是什麼：只用明亮的色調，畫面偏白、陰影很淡
範例中會發生的事：風景與人物都變成接近白色的明亮色彩，陰影非常淡，右下直方圖的峰移到最右端。
規格：
- 場景 3：左側為胸像（頭部中心 x 140, y 82，半徑 28 px），右側為山丘、房子、樹與太陽（x 432, y 54，半徑 15 px）。
- 顏色：天空 #FAF9F7 → #FFFFFF，山丘 #EAEDF1 → #F5F6F8，人物 #4D5A75 → #B9C0CE，陰影 #33405A → #A6AEBF，太陽 #F5A524 → #FFD889
- 直方圖（96×46 px，20 條）：峰的中心 0.56 → 0.85，寬度 0.2 → 0.09
- 時間：效果在 0.4–1.4 秒進入，維持到 4.0 秒，4.8 秒前恢復原狀（一個循環 5 秒，三次方緩入緩出，約等於 cubic-bezier(0.65,0,0.35,1)）
使用時機：用於想呈現潔淨、輕盈、溫柔感的商品或人物照片。
