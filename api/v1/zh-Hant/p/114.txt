請使用「Low Key（低調）」（Low-key），這是「攝影風格：光線、鏡頭與調色」裡的一個名稱。
Motion Prompt #114

它是什麼：以暗色調為主，只有受光處浮現出來
範例中會發生的事：畫面大半沉入黑暗，太陽也消失，只有從側面受光的胸像右緣亮著浮現出來；直方圖的峰移到最左端。
規格：
- 場景 3：左側為胸像（頭部中心 x 140, y 82，半徑 28 px），右側為山丘、房子、樹與太陽（x 432, y 54，半徑 15 px）。
- 顏色：天空 #FAF9F7 → #2B2D33，山丘 → #313339 與 #36383E，地面 → #24252A，人物 → #25272E；太陽與光環變成與天空同色而消失
- 胸像右緣的受光面保留，#FFC75A → #FFB547
- 直方圖：峰的中心 0.56 → 0.14，寬度 0.2 → 0.08
- 時間：效果在 0.4–1.4 秒進入，維持到 4.0 秒，4.8 秒前恢復原狀（一個循環 5 秒，三次方緩入緩出，約等於 cubic-bezier(0.65,0,0.35,1)）
使用時機：想營造高級感、緊張感或神祕氛圍時。
