請使用「長曝」（Long exposure），這是「攝影風格：光線、鏡頭與調色」裡的一個名稱。
Motion Prompt #107

它是什麼：快門開很久，讓移動的光變成線條
範例中會發生的事：街道轉為夜晚，行駛中的汽車淡到幾乎看不見，車後拉出一條紅色尾燈光軌，對向車道則有白色與琥珀色的光軌通過。
規格：
- 場景 2：街角。後方是一排建築、樹與路燈（x 114, 292, 494），道路在 y 132–162，人物站在左前方（腳底 x 176, y 200，身高 124 px）。顏色轉為夜晚（天空 #2C3B5E，每 3 扇窗中有 1 扇為 #FFC75A）
- 汽車：每 5 秒 x −60 → 600；車身不透明度 100% → 10%
- 尾燈光軌：從 x −60 畫到汽車所在位置：y 145 為 #FF5B4D 2.6 px，y 149 為 #FF8A6E 1.4 px
- 對向車道：橫跨整個畫面寬的線，y 135 為 #FFE9B8 2.6 px，y 138.5 為 #FFC75A 1.6 px，y 141.5 為 #FFE9B8 1.2 px（隨效果量變濃）
- 右上快門速度 1/250 → 8″
- 時間：效果在 0.4–1.4 秒進入，維持到 4.0 秒，4.8 秒前恢復原狀（一個循環 5 秒，三次方緩入緩出，約等於 cubic-bezier(0.65,0,0.35,1)）
使用時機：想用一張照片呈現夜晚車流，或如絲般流動的水與雲時。
