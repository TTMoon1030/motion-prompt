請使用「漣漪效果」（Ripple effect），這是「Landing Page 與網站效果」裡的一個名稱。
Motion Prompt #085

它是什麼：從點擊的位置向外擴散出波紋
範例中會發生的事：每次點擊時，白色圓形從點擊位置擴散、填滿按鈕，然後淡出消失。
規格：
- 按鈕 280 × 56（橘紅色，圓角 10）。在 0.7 秒（中心偏左）與 2.9 秒（中心偏右）各點擊一次。
- 圓心 = 點擊位置；半徑在 0.6 秒內從 0 擴大到點擊位置與按鈕最遠角的距離（三次方 easeOut）。
- 白色，不透明度 0.4，在點擊後 0.3–0.8 秒間淡出到 0。
- 圓形以按鈕的形狀裁切（overflow: hidden）；按鈕文字畫在圓形上方。
使用時機：想在按鈕或清單項目被按下的位置立即給出回饋時。
