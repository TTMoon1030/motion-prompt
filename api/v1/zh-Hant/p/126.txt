請使用「路徑動畫」（Motion path），這是「Motion Graphics 動態手法 第二彈」裡的一個名稱。
Motion Prompt #126

它是什麼：沿著設定好的曲線移動
範例中會發生的事：紙飛機沿著虛線路徑一邊轉向一邊前進，途中翻一圈。
規格：
- 每 4.7 秒一趟，從左側畫面外飛到右側畫面外。路徑為 x = 270 + 112θ − 150·sinθ、y = 106 − 74·cosθ（θ = −π→π），在中央上方繞出一個圈（翻圈）。
- θ 與時間成正比前進（所以沿路徑的速度不固定，繞圈的部分看起來較慢）。
- 紙飛機轉向路徑方向：角度 = atan2(74·sinθ, 112 − 150·cosθ)。
- 路徑事先以點線顯示（線寬 6，虛線 2/15）。飛過後留下 24 段薄荷綠軌跡（每段間隔 θ = 0.03），越後面越細越淡。
使用時機：需要沿固定路線移動時使用：飛行物、行駛的車、地圖上的旅程。
