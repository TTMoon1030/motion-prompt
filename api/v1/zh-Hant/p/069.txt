Motion Prompt #069

它是什麼：載入時以灰色方塊佔位
範例中會發生的事：點擊重新整理後，列表內容變成相同形狀的灰色方塊，並有光澤橫向掃過；載入完成後恢復內容。
規格：
- 4.5 秒循環，卡片 542×191。兩列的列表（每列一張 96×56 的圖片與三行文字）。游標在 1.0 秒點擊右上的重新整理圖示。
- 1.05–1.2 秒（線性）由內容切換為相同位置、相同大小的灰色 #e9e7e5 圓角方塊。
- 光澤：寬 160 的白色光帶（兩端透明，中央不透明度 0.75），每 0.9 秒由 x −200 掃到 x 742，只疊在方塊上。
- 3.0–3.3 秒（線性）恢復為內容。
使用時機：用於需要稍待片刻才載入完成的列表或卡片，讓人在等待時也能看到版面的形狀。
