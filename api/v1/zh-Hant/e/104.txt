// 藍調時刻 / Blue hour
// 包: photo (攝影風格：光線、鏡頭與調色) · element 08 · 分類: 打光方式與時段
// 會發生什麼: 太陽完全落下後，天空變成上下兩段深藍，建築的窗戶與路燈亮起琥珀色的光，人物成為深藍色的形狀。
// 動態規格:
//   - 場景 1：地平線（y 150）前方是胸部以上的人物（頭部中心 x 270, y 78，半徑 29 px，不畫五官與頭髮）。
//   - 太陽：半徑 18 px，位於 x 120，在效果量升到 70% 的期間由 y 40 落到 y 190，並在效果量 40–80% 之間淡出
//   - 顏色：天空上方 #2C3B5E、靠近地平線 #4A6191，地面 #283452，建築 #34446B，人物 #1C2439
//   - 燈光：每 3 扇窗中有 1 扇與路燈燈泡變成 #FFC75A；燈泡周圍有半徑 13 px 與 8 px 的平塗光環（#FFE3A3，35% 與 60%）
//   - 右上時間 12:00 → 18:35
//   - 時間：效果在 0.4–1.4 秒進入，維持到 4.0 秒，4.8 秒前恢復原狀（一個循環 5 秒，三次方緩入緩出，約等於 cubic-bezier(0.65,0,0.35,1)）
// 使用時機: 想讓夜景同時呈現天黑前的藍色天空與城市燈光時。
// 標籤: blue hour, twilight, dusk, night city, cityscape, deep blue sky
// 尺寸: 539x208 px · 一輪: 5 s
// Needs: kit photo -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/photo.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#104
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 08
// ブルーアワー: 日が沈んだ後、空が深い青になり、窓と街灯の暖かい光が灯る
CELLS[7] = cell((k, u) => {
  const a = env(u);
  const p = pal(BASE, NIGHT, a);
  stagePortrait(k, p, {
    sun: [120, lerp(40, 190, P(a, 0, 0.7)), 18, 1 - P(a, 0.4, 0.8)],
    after: D => { const k2 = D.k; k2.save(); k2.globalAlpha = 0.35 * a; D.circ(413, HZ - 53, 13, BASE.glow); k2.globalAlpha = 0.6 * a; D.circ(413, HZ - 53, 8, BASE.glow); k2.restore(); D.circ(413, HZ - 53, 4, p.bulb); }
  });
  bust(k, PX, PY, PR, p.person);
  hud(k, clock(lerp(720, 1115, a)));
});
