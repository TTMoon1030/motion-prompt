// 希區考克變焦 / Dolly zoom (Vertigo)
// 包: camera (運鏡與轉場) · element 08 · 分類: 鏡頭運動
// 會發生什麼: 攝影機一邊後退，一邊以相同比例變焦拉近；人物大小不變，只有背景往前逼近。
// 動態規格:
//   - 攝影機：與人物（前方 8 m）的距離 d 從 3.2 m 拉開到 8 m（後退 4.8 m）；高度 1.3 m
//   - 焦距：f = 330 × d/8 px，即 132 px → 330 px（顯示為 10mm → 24mm），讓距離與焦距的比值保持固定
//   - 時間：0.5 秒到 3.4 秒（2.9 秒），三次緩入緩出（相當於 cubic-bezier(0.65,0,0.35,1)）
//   - 被攝體：人物不動，在畫面中的高度維持不變；在頭頂（1.8 m）與腳下各畫一條寬 160 px 的藍色虛線，表示大小沒變
//   - 背景：建築（48 m 外）放大約 2.2 倍、山放大約 2.4 倍，在人物後方逼近；人物前方的地面反而縮小
//   - 復位：3.4–4.2 秒停住，最後 0.5 秒交叉淡化回起始狀態（一輪 4.7 秒）
// 使用時機: 表現人物察覺某事的瞬間，或用畫面呈現不安、震驚時。
// 標籤: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move
// 尺寸: 539x208 px · 一輪: 9.4 s
// Needs: kit camera -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/camera.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#032
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
