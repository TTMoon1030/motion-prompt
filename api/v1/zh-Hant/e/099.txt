// 剪影 / Silhouette
// 包: photo (攝影風格：光線、鏡頭與調色) · element 03 · 分類: 打光方式與時段
// 會發生什麼: 曝光逐步改以明亮的黃昏天空為準，人物、建築、路燈與樹都變成沒有細節的黑色形狀，只剩天空保持明亮。
// 動態規格:
//   - 場景 1：地平線（y 150）前方是胸部以上的人物（頭部中心 x 270, y 78，半徑 29 px，不畫五官與頭髮）。
//   - 天空：#FAF9F7 → 上方 #FFEDC4，靠近地平線的帶狀區域（y 92–150）為 #FFCF73
//   - 天空以外的形狀全部變成 #2A2D36，遠處山丘為 #4A4546；人物為 #22252D
//   - 太陽：半徑 20 px，在 x 404 從 y 60 落到 y 128，一半被山丘遮住
//   - 右上顯示：±0.0 EV → −2.0 EV
//   - 時間：效果在 0.4–1.4 秒進入，維持到 4.0 秒，4.8 秒前恢復原狀（一個循環 5 秒，三次方緩入緩出，約等於 cubic-bezier(0.65,0,0.35,1)）
// 使用時機: 以夕陽或明亮的窗戶為背景，想只靠外形與姿勢讓畫面留下印象時。
// 標籤: silhouette, backlit, sunset, contre-jour, black shape, underexposed
// 尺寸: 539x208 px · 一輪: 5 s
// Needs: kit photo -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/photo.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#099
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 03
// シルエット: 露出を明るい空に合わせると、人物も建物も木も黒い形だけになる
CELLS[2] = cell((k, u) => {
  const a = env(u), INK = '#2A2D36';
  const SILH = mapPal(BASE, () => INK);
  Object.assign(SILH, { sky: '#FFEDC4', sky2: '#FFCF73', far: '#4A4546', sun: BASE.sun, glow: BASE.glow });
  stagePortrait(k, pal(BASE, SILH, a), { sun: [404, lerp(60, 128, a), 20, a] });
  bust(k, PX, PY, PR, mixc(BASE.person, '#22252D', a));
  hud(k, `${(-2 * a).toFixed(1).replace('-0.0', '±0.0')} EV`);
});
