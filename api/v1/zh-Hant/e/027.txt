// 動態規格:
//   - 攝影機：往前（縱深方向）移動 0 m → 5.8 m；高度 1.5 m，方向與焦距（330 px，顯示為 24mm）固定

//   - 視差：前景的木樁（左 1.5 m、縱深 3.6 m）與岩石（右 1.6 m、縱深 4.8 m）在途中移出畫面；120 m 以外的山大小幾乎不變
//   - 復位：3.4–4.2 秒停住，最後 0.5 秒交叉淡化回起始狀態（一輪 4.7 秒）
//   - 右上角的顯示維持 24mm 不變（與 04 Zoom in 的差別）
// 使用時機: 想在保有空間縱深感的同時，靠近人物或某個細節時。
