// 手持 / Handheld
// 包: camera (運鏡與轉場) · element 10 · 分類: 拍攝手法與時間效果
// 會發生什麼: 在整個畫面加上細小而不規則的晃動，就像攝影機不是架在腳架上，而是用手拿著。
// 動態規格:
//   - 攝影機：位置幾乎固定；偏航（yaw）、俯仰（pitch）、滾轉（roll）與高度各自疊加多個週期不同的正弦波（T = 2π×u/4.7）
//   - 偏航角（rad）= 0.016·sin(3T) + 0.008·sin(7T+1) + 0.004·sin(13T+2)，最大約 ±1.6°
//   - 俯仰角（rad）= 0.012·sin(4T+2) + 0.006·sin(9T+0.5) + 0.003·sin(17T+1.2)，最大約 ±1.2°
//   - 滾轉角（rad）= 0.02·sin(5T+1) + 0.008·sin(11T+3)，最大約 ±1.6°；高度 = 1.5 + 0.03·sin(6T) m
//   - 被攝體：人物靜止站在前方 6.5 m 處；晃動持續不斷，沒有緩動也沒有停住
//   - T 的倍率全為整數，因此每 4.7 秒無接縫循環；右上角顯示「HANDHELD」
// 使用時機: 要營造紀錄片般的臨場感，或身在現場的感覺時。
// 標籤: handheld, camera shake, shaky, documentary, wobble, noise, realism
// 尺寸: 539x208 px · 一輪: 9.4 s
// Needs: kit camera -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/camera.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#034
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 10
// 10 手持ち
CELLS[9] = shot((k, w, h, u) => {
  const T = u * 2 * Math.PI / CYC;   // 周期をサイクルに合わせて継ぎ目なし
  const n = (a, b, c2) => Math.sin(T * a + b) * c2;
  const yaw = n(3, 0, .016) + n(7, 1, .008) + n(13, 2, .004), pitch = n(4, 2, .012) + n(9, .5, .006) + n(17, 1.2, .003), roll = n(5, 1, .02) + n(11, 3, .008);
  world(k, w, h, cam({ yaw, pitch, roll, y: 1.5 + n(6, 0, .03) }), { person: { z: 6.5 } });
  return 'HANDHELD';
});
