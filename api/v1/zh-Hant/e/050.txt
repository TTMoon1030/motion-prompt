// 會發生什麼: 點擊「選單」後，一塊直長的面板從左側滑出；點擊面板外側即滑回。
// 動態規格:
//   - 4.5 秒循環，卡片 542×191。游標在 1.0 秒點擊左上的「選單」按鈕（110×34）。
//   - 開啟量 a：1.0–1.38 秒以 easeOutCubic 由 0→1。整張卡片鋪上 rgba(18,20,28) 遮罩，不透明度 0.36×a。
//   - 面板：白色、寬 210、與卡片等高，x = −210 + 210×a，從左緣滑入。陰影 blur 22、濃度 0.25。
//   - 面板內：上方是圓形頭像（半徑 14）與名稱，下方是間隔 32 px 的四列選單；第一列以淺藍色色帶標示為選取中。
//   - 關閉：游標在 3.3 秒點擊面板外的 (420, 120)；a 乘上 (1 − easeInOutCubic(3.3–3.65 秒))，面板滑回左側。
// 使用時機: 想把導覽選單或篩選條件等佔空間的操作先收在側邊、需要時再拉出時使用，手機上尤其常見。
// 標籤: drawer, off-canvas, offcanvas, side-menu, navigation-drawer, sheet, sidebar, slide-in
// 尺寸: 542x191 px · 一輪: 4.5 s
// Needs: kit ui -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/ui.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#050
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 02
// 02 ドロワー（Drawer (Off-canvas)）
CELLS[1] = ui((w, h, t) => {
  strokeRR(24, 14, 110, 34, 8, C.line2, 1.5); text('メニュー', 79, 31, 15, '#555', 600, 'center');
  bar(160, 26, 140, C.line2, 11); pageLines(24, 70, 494); fillRR(24, 138, 494, 42, 8, C.block);
  const a = eo(seg(t, 1.0, 1.38)) * (1 - eio(seg(t, 3.3, 3.65)));
  if (a > 0) {
    X.fillStyle = `rgba(18,20,28,${.36 * a})`; X.fillRect(0, 0, w, h);
    const pw = 210, px = -pw + pw * a;
    shadowed(() => { X.fillStyle = '#fff'; X.fillRect(px, 0, pw, h); }, 22, 0, .25);
    circle(px + 34, 32, 14, C.mb); bar(px + 58, 27, 100, C.line2, 10);
    for (let i = 0; i < 4; i++) { const y = 62 + i * 32; if (i === 0) fillRR(px + 12, y - 2, pw - 24, 28, 6, C.lb); fillRR(px + 22, y + 5, 14, 14, 3, i === 0 ? C.blue : C.line2); bar(px + 46, y + 7, 90 + (i % 2) * 30, i === 0 ? C.sb : C.line); }
  }
  pointer([[.3, w + 30, h + 30], [.95, 70, 34], [1.6, 70, 34], [3.0, 420, 120], [3.6, 420, 120], [4.2, w + 30, h + 30]], [1.0, 3.3], t);
});
