// 分割畫面 / Split screen
// 包: motion2 (Motion Graphics 動態手法 第二彈) · element 24 · 分類: 轉場與吸睛效果
// 會發生什麼: 整個畫面的場景先分成 2 格，再分成 3 格，每格裡各有自己的場景在動。
// 動態規格:
//   - 全畫面的海景在 0.45–0.95 秒分成 2 格（分隔線 539→269.5），1.4–1.9 秒分成 3 格（分隔線在 1/3 與 2/3），3.75–4.4 秒合併回 1 格，全部為 easeInOut（三次）。
//   - 3 個場景（海、城市、草原）各自置中並裁切在自己的格子內，持續動態（海浪與帆船、城市窗戶每 4.7 秒切換 8 次、風車每 4.7 秒轉 2 圈）。
//   - 格子之間有白色分隔線（寬 6）。
// 使用時機: 用來比較、呈現同時發生的事，或並列多個人物或地點，例如前後對比或多個選項。
// 標籤: split-screen, multi-screen, panels, side-by-side, comparison, layout
// 尺寸: 539x208 px · 一輪: 4.7 s
// Needs: kit motion2 -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/motion2.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#144
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 24
// 24 スプリットスクリーン（1枚の画面が2つ、3つに分かれて、別々の場面が同時に動く）
CELLS[23] = (k, w, h, u) => {
  u = snapU(u);
  const s2 = eIO(P(u, 0.45, 0.95)), s3 = eIO(P(u, 1.4, 1.9)), m = eIO(P(u, 3.75, 4.4));
  let b1 = lerp(lerp(w, w / 2, s2), w / 3, s3), b2 = lerp(w, 2 * w / 3, s3);
  b1 = lerp(b1, w, m); b2 = lerp(b2, w, m);
  pnSea(k, 0, b1, h, u, false);
  if (b1 < w - 0.5) pnCity(k, b1, Math.max(b1, b2), h, u, false);
  if (b2 < w - 0.5) pnField(k, b2, w, h, u, false);
  k.fillStyle = '#fff';[b1, b2].forEach(b => { if (b < w - 0.5) k.fillRect(b - 3, 0, 6, h); });
};
