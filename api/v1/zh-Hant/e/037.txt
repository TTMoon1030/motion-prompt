// 慢動作 / Slow motion
// 包: camera (運鏡與轉場) · element 13 · 分類: 拍攝手法與時間效果
// 會發生什麼: 在固定的攝影機前，人物緩慢地跳起又落下，葉子也緩緩飄落；整段動作被拉長。
// 動態規格:
//   - 攝影機：完全固定（高度 1.3 m）；只有被攝體在動
//   - 被攝體：7 m 外的人物花 3.8 秒完成一次跳躍（0.5 秒到 4.3 秒）；高度 = 4q(1-q)×1.1 m，是頂點 1.1 m 的拋物線，q 隨時間等速增加
//   - 騰空時雙臂舉起；起跳前 0.5 秒與落地後 0.4 秒站著不動
//   - 葉子：9 片葉子一邊旋轉一邊從 3.4 m 高落到地面，歷時 4.7 秒，相位各錯開週期的 1/9 並循環
//   - 右上角顯示「120fps ×0.25」（設定為拉長 4 倍播放）
//   - 沒有停住，也沒有交叉淡化；每 4.7 秒無接縫循環
// 使用時機: 要讓觀眾細看短暫的動作或表情，或強調情緒高潮時。
// 標籤: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 尺寸: 539x208 px · 一輪: 9.4 s
// Needs: kit camera -> https://ttmoon1030.github.io/motion-prompt/api/v1/kit/camera.js
// 會動的範例: https://ttmoon1030.github.io/motion-prompt/#037
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫端已清除畫面並包好 save/restore），w、h = 尺寸，u = 秒數（0 以上、未滿一輪）。畫面只由 u 決定。
// 以下是元素的程式碼。CELLS、常數與輔助函式都在 kit 裡。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
